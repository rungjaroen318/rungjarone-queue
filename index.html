iPhone / iPad เปิดผ่าน Safari

  1. เปิดลิงก์หน้าเว็บนี้ในแอป Safari
  2. แตะปุ่ม แชร์ (Share ⬆️) ที่แถบด้านล่างของหน้าจอ
  3. เลื่อนลงมาแล้วแตะ "เพิ่มไปยังหน้าจอโฮม" (Add to Home Screen)
  4. กด "เพิ่ม" (Add) มุมขวาบน จะได้ไอคอนแอปบนหน้าจอมือถือทันที

Android เปิดผ่าน Google Chrome

  1. เปิดลิงก์หน้าเว็บนี้ในแอป Chrome
  2. แตะปุ่ม จุด 3 จุด (⋮) ที่มุมขวาบน
  3. เลือก "เพิ่มลงในหน้าจอหลัก" (Add to Home screen)
  4. กด "เพิ่ม" เพื่อสร้างไอคอนเปิดใช้งานได้ทันที
